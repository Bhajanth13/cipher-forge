How a message travels

Five layers, one composition

  1. Message. What you type on the sender.
  2. F, your cipher. Encrypted with the shared key. Unreadable without it.
  3. code. Each character becomes a number from 0 to 255.
  4. hex. Each number splits into two base-16 digits.
  5. tones. Each digit becomes one of 16 frequencies in the air.

send = tones ∘ hex ∘ code ∘ F

receive = F⁻¹ ∘ code⁻¹ ∘ hex⁻¹ ∘ tones⁻¹

The receiver undoes each layer, last one first: the inverse of a composition, from Module 3.

01 · Message

02 · F: your cipher

03 · code: character → 0–255

04 · hex: two base-16 digits

05 · tones: digit → frequency

Why it works

Loud, public, and still private

01

Everyone can hear it

The tones fill the room like a radio broadcast. Hiding the signal is not the goal.

02

Only the key reads it

Without the key, a listener gets ciphertext. Break it in the lab shows what they could still try.

03

Nothing is lost silently

The sum of the character codes mod 256 travels with the message. One misheard tone and the check fails.

04

Silent if you want

No Wi-Fi, no pairing, no server. In silent mode the tones sit at 17–19.2 kHz, above what most people can hear.
