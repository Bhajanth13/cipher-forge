Whisper

A flagship cipher pager for covert work.

Type on a full-face touch e-paper screen, tap Send, and your message leaves encrypted as near-silent tones. Whisper has no radio at all: a titanium and ceramic body the size of a credit card, with the key locked in a secure chip.

    Inside the firmware

    From air to screen

    The same maths as the lab, running on the chip. Receiving undoes the chain in reverse order: (fk ∘ … ∘ f1)⁻¹ = f1⁻¹ ∘ … ∘ fk⁻¹.

    Receive

    1. Tones in the air16.9–18.9 kHz
    2. Dual microphones2 × ICS-43434, I²S
    3. 16 tone detectorsGoertzel, one per digit
    4. Digits to bytes16 × 16 = 256, sum mod 256
    5. DecryptF⁻¹, key from SE050
    6. E-paper + buzzplaintext, never stored

    Send

    1. Touch keyboardon-screen, can be scrambled
    2. EncryptF = fk ∘ … ∘ f1
    3. Bytes to digitstwo base-16 digits each
    4. Digits to tones200 ms per tone
    5. AmplifierMAX98357A, I²S
    6. Speakera few metres, then silence

    Field protocol

    Built to go unnoticed

    No radio at all

    There is no Wi-Fi, Bluetooth or cellular chip, so a radio scanner finds nothing. Whisper talks only through sound and its USB port.

    A near-silent channel

    Tones between 16.9 and 18.9 kHz are above most adults’ hearing and fade within a few metres, so the message stays in the room.

    Shoulder-proof typing

    The keyboard is drawn on the screen: no clicks, and its layout can be scrambled each time so nobody can read your taps.

    No glow

    E-paper reflects light instead of giving it off, and there are no LEDs. In a dark room the unit is invisible.

    Fingerprint unlock

    The power key reads your fingerprint. Until it matches, the secure chip will not release the key.

    Mic kill switch

    A physical slider cuts power to both microphones. No software can turn them back on.

    Silent alerts

    A short buzz pattern says a message arrived. No sound, no light.

    Panic wipe

    Hold the thumb rotor for five seconds and the secure chip erases the key. Every message sent with it becomes unreadable.

    Tamper response

    Opening the case lets light reach a sensor inside, and the keys are erased before anyone can probe the board.
