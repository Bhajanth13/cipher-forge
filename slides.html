    02 · Module 1 · Sets

    Every cipher starts with a set

    The symbols a cipher can use form a set S. Its size, the cardinality |S|, decides how many keys exist and which blocks are safe.

    Roster
    S = {A, B, C, …, Z}
    Set-builder
    S = { x | x is a capital English letter }
    Cardinality
    |S| = 26
    Pairs
    |S × S| = 26 × 26 = 676
    Subsets
    Σ C(26, r) = 2²⁶ = 67,108,864

    03 · Module 3 · Functions and composition

    A cipher is a function, built from blocks

    Each block is a function f : S → S on positions A = 0 … Z = 25. Running f₁ then f₂ is the composition f₂ ∘ f₁.

    • shift(k) x ↦ (x + k) mod 26
    • multiply(a) x ↦ a·x mod 26
    • mirror x ↦ 25 − x
    • swap(p, q) exchanges two letters

    Composition is associative, so a chain of k blocks can be bracketed in Cₖ₋₁ ways (the Catalan number) and every bracketing gives the same cipher.

    f₁shift(3)
    f₂multiply(5)
    f₃mirror

    1. H = 7
    2. f₁: 7 + 3 = 10 → K
    3. f₂: 5 × 10 = 50 ≡ 24 (mod 26) → Y
    4. f₃: 25 − 24 = 1 → B

    04 · Modules 2 and 3 · Logic, bijections, pigeonhole

    It can be undone only if it is a bijection

    One-to-one (I)
    ∀x₁, x₂ ∈ S : f(x₁) = f(x₂) → x₁ = x₂
    Onto (O)
    ∀y ∈ S ∃x ∈ S : f(x) = y
    Decryptable (V)
    V ⇔ I ∧ O

    Multiply by 2 sends A (0) and N (13) to the same letter A, because 2 × 13 = 26 ≡ 0. Two letters, one output: by the pigeonhole principle some letter is never reached.

    multiply(a) is a bijection exactly when gcd(a, 26) = 1: that leaves 12 safe values of a.

    multiply(3): a bijection

    26 inputs · 26 different outputs

    05 · Modules 1 and 3 · Relations and inverses

    A relation, its inverse, and the round trip

    A function is a relation R = { (x, F(x)) } ⊆ S × S. Drawn as a grid, a bijection has exactly one dot in every row and every column: a permutation matrix.

    Decryption runs the inverses in reverse order, because (g ∘ f)⁻¹ = f⁻¹ ∘ g⁻¹.

    F⁻¹ = f₁⁻¹ ∘ f₂⁻¹ ∘ f₃⁻¹ = shift(−3) ∘ multiply(21) ∘ mirror

    21 undoes 5 because 5 × 21 = 105 = 4 × 26 + 1.

    06 · Modules 1, 3 and 4 · Multisets, pigeonhole, brute force

    Break it with only the ciphertext

    Brute force tries every key. A shift cipher has 26, so the attacker simply reads all of them.

    Frequency analysis counts letters. The message is a multiset; a substitution is a bijection that only relabels letters, so the sorted counts keep English’s shape and the top cipher letter is very likely E.
